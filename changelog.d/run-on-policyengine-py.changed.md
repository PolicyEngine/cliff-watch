CliffWatch now runs on `calculate_household` from policyengine.py, whose `us` extra sets the engine: policyengine-us 2.2.1, policyengine-core 3.33.3 and spm-calculator 1.0.0. SNAP and WIC amounts now sum the calendar year rather than multiplying January by twelve, so they include each October's cost-of-living change. A household needs someone aged 18 or older, and years outside 2022 to 2035 now raise, because the engine's default outputs measure SPM poverty. Every adult now counts as working 40 hours a week, which the old engine assumed by default and the new one doesn't, so SNAP's time limit, child care activity tests and Medicaid's 2027 work test pass as they did.
