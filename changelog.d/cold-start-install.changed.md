On a cold start, Vercel's Python runtime installs the public packages into `/tmp` again, because policyengine.py and its engine take the function past the 225 MiB that the runtime bundles. A complete install still fits beside the files a stopped attempt leaves behind. `/api/calculate`, `/api/series` and `/api/households` get 120 seconds rather than 60, since the first request on an idle instance takes 44 to 58 seconds.
